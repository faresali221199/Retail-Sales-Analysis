# 📊 Retail Sales Data Analysis (End-to-End Project)

A comprehensive data analysis project exploring retail sales trends, product profitability, and geographic distribution using Python, Pandas, and an interactive Power BI Dashboard.

---

## 🚀 Project Overview
This project processes and analyzes retail sales data to extract actionable business insights. It includes cleaning raw datasets, handling missing or misformatted records (like case-sensitivity issues in text columns), and answering key business questions regarding top-performing retailers, high-profit products, and regional sales performance.

---

## 🛠️ Tech Stack & Libraries
* **Python** (v3.11+)
* **Pandas & NumPy** (Data manipulation, grouping, and analysis)
* **Power BI Service** (Interactive data visualization & dashboards)
* **Jupyter Notebook** (Interactive development environment)
